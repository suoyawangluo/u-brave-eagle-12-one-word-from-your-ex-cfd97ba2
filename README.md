One word, the word your ex would use to describe you: **unread**. The messages left unread, and a person nobody ever really read.

## Run it

```sh
node main.ts
```

It writes `unread` to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), after checking the 1–24 character, single-word gate and verifying the file by reading it back.
